# Sylcla

纯宝与秦彻的私人梦向档案。黑底红调，开屏动画来自《莫比乌斯环（双文案）》。

全站六个板块各自独立成一页：

| 页面 | 内容 |
| --- | --- |
| 档案 | 两个人的人物档案 + 纪念日：照片、姓名、年龄、身高、身份、生日、地点、性别、自我介绍、外貌、习惯、喜恶、个人经历（分节点）、纹章 |
| 设定集 | 人物、地点、世界观等自由设定，含「人物关系」；可新增 / 编辑 / 删除 |
| 点滴 | 短句 + 图片的时间线，图片按竖版 4:3（宽 3 : 高 4）展示 |
| 邮箱 | 寄出 / 收到的信，有主题和正文 |
| 你我之间 | 钉在墙上的短句 + 图片，可带地点与心情 |
| 通话 | 通话与聊天二合一：日期、时长、备注，可附聊天记录；从图片导入的聊天也带通话时长，点开就是黑底白字气泡 |

**档案与设定集是两件事**：档案是两个人的身份页；设定集是这个世界观里所有可自由添加的设定条目。

- 点导航上的「访客」，输入密码 `20240715` 后才进入 **管理员模式**，编辑按钮才会出现。

## 图片与比例

- 档案照片、点滴图片、你我之间图片都按 **竖版 4:3（3:4）** 展示，上传时自动压缩到 900px 以内。
- 档案照片与图片都存在浏览器本地，不会上传。
- 点滴、你我之间、设定集、邮箱、空间、通话的编辑都受管理员密码保护。

## BGM

- 本地播放列表六首：不设防禁区 / French Movie Waltz / 灰绣球 / You Are All I Need / Forever / Trees don't speak。
- 进入开屏点击「进入」后自动播放第一首；若浏览器拦截自动播放，第一次点击页面任意位置时开始。
- 播放器是 **可拖拽的小悬浮窗**，默认在左上角，开始播放后出现；按住顶部拖动到任意位置，位置会记住。
- 默认只显示黑胶、歌名和播放控制；点 `≡` 才展开六首曲目列表。
- 播放器带黑胶旋转、均衡器跳动和进场动效：播放 / 暂停、上一首、下一首、点任意一首切换；播完自动下一首循环。
- 当前曲目会记在 `localStorage` 的 `sylcla.bgm.track`，下次进入从这首开始。
- 音频在 `assets/audio/`，都是本地 MP3，不依赖外部链接。

## 通话与聊天

「通话」页只有一个入口「＋ 记录通话」：

- **通话时长是必填流程**：先填日期和通话时长，才能保存；不填会提示。
- 聊天截图是可选的：不选图片也能保存一条只有时长和日期的通话；**一次可选多张**，分几次选也会**追加**到已有消息，不会覆盖。
- 每条通话/聊天记录都要选 **来电** 或 **拨出**。
- 保存后列表只显示来电/拨出和通话时长，不显示聊天条数或内容；点开并输入密码后才显示聊天记录。
- 识别后校对文字和说话人，保存为同一条记录；列表显示「X 分钟」，点开就是黑底白字气泡。
- 聊天记录同样可以点「编辑」改日期、时长和备注，聊天内容不会丢。

识别优先用本地 PaddleOCR（PP-OCRv5），失败时回退 Tesseract。

### 导入聊天记录文件

如果截图识别不稳定，可以直接导入微信导出工具生成的文件：

- 支持 `.csv` / `.json` / `.txt` / `.html`；
- CSV 支持 `IsSender`、`StrContent`、`Type` 这类列；
- JSON 支持 `isSender`、`content`、`text`、`from` 等字段；
- TXT 用「我：」「他：」开头，一行一条；
- 导入后仍然在列表里校对，再填时长和来电/拨出保存。

### AI 识别（可选）

「记录通话」→「AI 识别设置」里可以填任意 OpenAI 兼容的接口：

- **DeepSeek（视觉识别）**：直接把截图发给 DeepSeek 视觉模型，识别成对话 JSON；小图会先放大；
- **OpenAI / 通义千问 / Gemini**：同样直接识图；可选「本地 OCR + AI 整理」模式。
- 预设：DeepSeek / OpenAI / 通义千问 DashScope / Google Gemini / 自定义；
- 填 API Base、模型、API Key，保存后优先走 AI，失败自动回退本地结果；
- Key 只存在这台设备的 localStorage，不会写进代码；
- 不填 Key 时完全在本机识别；填了之后图片或 OCR 文字会发送给你配置的服务商。

默认已经配好 **本地 DeepSeek 代理**：

- 代理地址：`http://127.0.0.1:8787/v1`，模型 `deepseek-chat`；
- Key 只放在项目根目录的 `ai-key.txt`，不会出现在网页源码里；
- 启动代理：双击项目根目录的 `start-ai-proxy.bat`，或运行 `node ai-proxy.js`；
- 代理没启动时，AI 请求会失败并自动回退本地识别。

DeepSeek 模式下截图会发送给 DeepSeek 视觉模型；不填 AI 时完全在本机识别。

## 打开方式

推荐本地 HTTP 服务（PaddleOCR 的 Worker 和本地模型都需要）：

```powershell
python -m http.server 4173 --bind 0.0.0.0 --directory .
# http://127.0.0.1:4173/
```

### 手机 / 平板

- 手机、平板和电脑连同一个 Wi-Fi；
- 电脑上双击 `启动Sylcla.bat`（会同时启动网站和 AI 代理）；
- 手机浏览器打开 `http://电脑的局域网IP:4173/`；
- 例如这台电脑是 `http://192.168.124.4:4173/`；
- 如果打不开，检查 Windows 防火墙是否放行 Python 的 4173 和 Node 的 8787 端口；
- 手机端图片选择器可能只允许一次选一张，选第二张会追加，不会覆盖；
- 只想在公网访问时，需要把静态站点部署到 Netlify / Vercel / GitHub Pages 等，并单独部署 AI 代理；本地的 `ai-proxy.js` 只在局域网可用。

开屏参数：`?splash=1` 强制播放、`?splash=0` 跳过；普通访问同一标签页只播放一次，导航/页脚的「开屏」可重播。

## 数据
